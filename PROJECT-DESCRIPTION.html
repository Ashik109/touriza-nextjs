Touriza — Tour & Travel Next.js Template

Touriza is a modern, responsive, and feature-rich tour and travel Next.js template created for travel agencies, tour operators, destination guides, adventure companies, hiking businesses, yacht charters, camping services, travel marketplaces, and tourism websites.

Built with Next.js 16, React 19, and TypeScript, Touriza includes ten professionally designed homepage concepts, multiple tour listing layouts, dynamic tour, destination, and blog detail pages, smooth animations, responsive sliders, and a working contact form. Its organized component structure makes the template practical for developers who need a polished travel website that is easy to customize and extend.

Working Contact Form

The contact page includes browser and server-side validation, a loading state, success and error feedback, spam honeypot protection, and automatic reset after a successful submission.

Configuration note: the included form uses FormSubmit for email delivery. The recipient email must be activated after the first submission, or the Server Action can be connected to another JSON form endpoint through the CONTACT_FORM_ENDPOINT environment variable.

Requirements and Important Notes

  • Node.js 20.9 or newer is required.
  • This is a Next.js template, not a WordPress theme.
  • Sign-in and sign-up pages provide frontend UI only; authentication backend integration is not included.
  • Tour booking, payment, user accounts, and database functionality require separate backend integration.
  • Contact delivery requires FormSubmit activation or a custom endpoint.
  • Basic knowledge of React, Next.js, TypeScript, HTML, and CSS is recommended for customization.
Preview asset notice: photographs and other third-party preview assets may be used for demonstration purposes only and may not be included in the downloadable package. Review the included documentation for complete asset and library credits before submission.

Customization and Documentation

The project follows a clear folder structure. Page sections are grouped by route, shared browser behavior is centralized in reusable controllers, dynamic content is stored separately, and global design overrides are kept in one stylesheet. The included HTML documentation explains installation, commands, source locations, content editing, slider configuration, contact setup, and maintenance.
